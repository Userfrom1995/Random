## Why

The owner order fixes the stack (ECharts, SVG, offline), the template
sameness rule (neutrality guarantee), the design bar (one message per
chart, labeled axes with units, shared color, N/A marked, no truncated
axes), and the two-tier verification gate. This blueprint turns those
orders into module boundaries and test contracts the Builder can execute.

## How It Works

Data flows one way: committed `results/m1/medians.json` plus
`results/m2/medians.json` plus `results/report.json` -> `charts.py`
generates option JSON per page -> static HTML pages load vendored ECharts
-> SVG renderer draws -> loader fetches option JSON at serve time. No
hand-typed chart values exist anywhere; hallucination has nowhere to enter.

Identical template, seven sections per pooler page (section ids fixed,
order fixed, enforced by test): header plus version pin; own-surface
charts; flatness verdict; config anatomy; data-bound strengths/limits;
N/A table; repro pointer. Strengths/limits are derived strings from
`report.json` ranked verdicts (best count, inconclusive count, timeout
count), never free prose. Nav runs both ways: comparison page links each
pooler page; each pooler page links back plus prev/next across poolers in
fixed rotation pgagroal, PgBouncer, pgpool-II, Odyssey, pgcat.

Shared palette (Okabe-Ito, dark-background legible, one color per pooler
on all six pages): pgagroal vermillion `#D55E00`, PgBouncer blue
`#56B4E9`, pgpool-II yellow `#E69F00`, Odyssey bluish-green `#009E73`,
pgcat reddish-purple `#CC79A7`, direct gray `#9AA7B4`. N/A gray `#484F58`
with explicit N/A marker, never gap-filled. Axes start at zero unless a
zoomed inset is paired beside a full-range twin (no silent truncation).

Chart features on every figure: per-point markers always visible, hover
tooltips with exact values plus config and cell id, dataZoom plus legend
series toggles, min-max bands rendered as ECharts custom or error-bar
series, `toolbox.feature.saveAsImage` PNG export enabled.

## Module Breakdown

- `poolduel/vendor/`: pinned ECharts dist plus upstream LICENSE plus
  `poolduel/vendor/VERSION` (version string plus dist URL plus sha256).
  Pin `5.5.1`; if the dist URL is unreachable at build time, pin the
  nearest 5.x with a working dist and record why in VERSION.
- `poolduel/harness/charts.py`: `build_options(m1, m2, bundle)` returns
  per-page option dicts (comparison plus one per pooler); CLI
  `--out poolduel/results/charts` writes one JSON per page plus a
  `manifest.json` (source SHAs of the three input bundles). Loud failure
  on missing inputs. Repro: `repro.sh --charts` runs report then charts.
- `poolduel/assets/poolduel-charts.js`: single loader used by all six
  pages; `echarts.init(el, null, {renderer: "svg"})` only; fetches the
  page option JSON; no inline data.
- `poolduel/<pooler>/index.html` (five files, one template): seven fixed
  sections; charts mount into `<div class="echart" data-chart="...">`
  hosts the loader fills.
- `poolduel/index.html`: comparison tables plus comparison graphs (M1
  best-vs-best per workload, M2 block heads, iso-region overlays on
  shared geometries, flatness strip across poolers) plus published banner.
- `poolduel/tests/test_charts.py`: Tier-1 gate (see Test Matrix).
- `poolduel/ci/vision-shots.sh` (or same-named script): Tier-2 loop
  wiring: serves `poolduel/`, screenshots every chart host headless,
  stores PNGs under `/tmp` (never committed), prints the per-chart file
  list for the verification run.

## Test Matrix

- Tier-0 (first, blocking the Tier-2 build): fixture vision probe. Serve
  one fixture chart, screenshot, feed the PNG back to the agent, read one
  known median. Pass proves the pinned model can see; fail pins a
  vision-capable free model for verification runs and Tier-1 carries the
  gate meanwhile. Probe result committed as a one-line note in the M4 PR
  body, never as code.
- Tier-1 deterministic (blocking merge, no vision needed): rendered SVG
  coordinates encode fixture medians (parse option JSON plus spot-check
  SVG node positions against bundle medians); template sameness (section
  id set equality across all five pages); shared-color consistency (each
  pooler maps to its palette hex on every page); N/A markers present with
  zero gap-fill (option data contains explicit N/A points); zero hand
  values (options JSON deep-equals a fresh `charts.py` run on fixtures);
  `node --check` on the loader; full unittest suite green.
- Tier-2 vision (blocking merge once Tier-0 passes): screenshot every
  chart on all six pages, read all values per cell/arm from the PNGs,
  compare to bundle medians, verify labels/legend/axes; mismatch fails.
- Standard gates: Reviewer audit (anti-theater checklist on the new
  pages), Tester sample-cell repro plus Tier-1 re-run, Pages deploy green
  with numbers live and zero pending banners.
