# Resonata

A real-time, dependency-free polyphonic audio synthesizer written in **C**, compiled
both to a **native test binary** (for a headless DSP test suite) and to **WebAssembly**
(for a fully client-side browser instrument hosted on GitHub Pages at
`/resonata/index.html`). Resonata's thesis is *legibility*: every stage of the
signal path is readable, tweakable code you can hear instantly, with a pure,
deterministic, allocation-free-on-the-hot-path DSP core that is provably the same
library whether it runs in a native test or inside a browser AudioWorklet.

This blueprint builds on Dr. Mob's research spec (`docs/resonata-research-spec.md`,
PR #101, closes #100). It fixes the software architecture, module boundaries, the
exact C/WASM ABI, the build pipeline, the UI, and the test matrix so the Builder
can ship the core before any UI.

## What Will Be Built

A single C library (`core/`) implementing the full signal path from the spec:

```
oscillator(s) --> mixer --> biquad filter --> ADSR-scaled VCA --> voice sum --> tanh soft-clip --> master
```

plus a fixed voice pool with voice-stealing polyphony, a mipmapped wavetable bank,
a minimal versioned JSON patch parser, and a clean state-in / state-out engine
boundary. The same `core/` sources compile to:

- a native test binary (`build/resonata_test`) run by a hand-rolled `assert`
  harness (no browser, no framework) covering every numeric claim in the spec; and
- a standalone `resonata.wasm` (`STANDALONE_WASM=1`, no emscripten JS runtime) that
  is instantiated *inside* an `AudioWorklet` for true sample-accurate real-time
  audio, wrapped by a tiny hand-written ES-module glue.

A browser front end (`ui/`) provides an oscilloscope, an ADSR/filter/oscillator
control surface, a clickable + computer-keyboard piano, and JSON patch load/save.
Everything is static and client-side; no backend.

## Why

The lab already owns audio-adjacent tooling (Cadence sonifies sorting; Beambus is a
retro shooter with chiptune-style sound) but nothing that is a *real* synthesizer
with a rigorous, testable DSP core. Resonata fills that gap with genuine engineering
depth: phase-accumulator oscillators with PolyBLEP anti-aliasing, mipmapped
wavetable synthesis, exponential ADSR, RBJ biquad filters in transposed Direct Form
II, and a WASM/C ABI with explicit complexity bounds. The "core first, UI second"
discipline also gives the lab a reproducible, browser-free numeric test target,
which none of the existing audio projects have.

## How It Works

### 1. Module boundaries

```
resonata/
  core/                 # the DSP library: pure C, no platform code, no heap on hot path
    resonata.h          # public C ABI (the 7 resonata_* functions + enums + structs)
    osc.h / osc.c       # phase accumulator + naive + PolyBLEP (saw/square/triangle) + sine
    wavetable.h / .c    # mipmapped table bank generation + interpolated read
    adsr.h / .c         # exponential ADSR state machine
    biquad.h / .c       # RBJ cookbook coeffs + transposed Direct Form II step
    voice.h / .c        # per-voice signal path: osc -> mixer -> filter -> VCA
    patch.h / .c        # Patch struct + minimal JSON parser/serializer
    json.h / .c         # tiny recursive-descent JSON reader (no external dep)
    engine.h / .c       # ResonataEngine: voice pool, note on/off, stealing, render
  wasm/
    exports.c           # STANDALONE_WASM entry: just declares the 7 resonata_* exports
  ui/
    index.html          # entrypoint, mounted at /resonata/index.html
    resonata.js         # ~40-line ES glue: instantiate wasm, wrap the 7 functions, marshal JSON
    worklet.js          # AudioWorkletProcessor: owns the wasm engine, renders per block
    main.js             # UI wiring: controls, piano, scope, patch load/save
    styles.css
    default-patch.json  # the canonical v1 patch (Pages-readable)
  test/
    fft.c / fft.h       # small in-place radix-2 FFT for frequency-domain assertions
    test_harness.h      # RES_ASSERT / runner macros
    test_osc.c          # FFT peak + PolyBLEP alias rejection
    test_wavetable.c    # RMS match to analytic sum + no cross-table pop
    test_adsr.c         # attack/decay/release timing
    test_biquad.c       # magnitude response per type + impulse finiteness
    test_poly.c         # voice alloc/free + stealing picks quietest
    test_patch.c        # JSON round-trip + clamping + bad-JSON-no-crash
    test_e2e.c          # 0.5 s note follows ADSR envelope shape
  Makefile              # `make test` (native) and `make wasm` (STANDALONE_WASM)
```

The hard rule from the spec is preserved: `core/` contains **no** `malloc` on the
render path and **no** hidden global state. `resonata_create` allocates the entire
voice pool and wavetable bank once; `resonata_render` only reads/writes
pre-allocated structs.

### 2. Data structures (the Builder's contracts)

```c
typedef enum { OSC_SINE, OSC_SAW, OSC_SQUARE, OSC_TRIANGLE, OSC_WAVETABLE } OscKind;
typedef enum { FILT_LP, FILT_HP, FILT_BP_PEAK, FILT_BP_SKIRT, FILT_NOTCH,
               FILT_PEAK, FILT_LOWSHELF, FILT_HIGHSHELF } FilterType;

typedef struct {
  OscKind kind;
  double  detune_cents;     // -100..100 typical; applied as f *= 2^(c/1200)
  double  level;            // 0..1 per-osc mix
  int     wavetable_id;     // index into bank when kind == OSC_WAVETABLE
  double  phi;              // phase in [0,1)
  double  prev_phi;         // previous phase, for wrap/discontinuity detection
  double  sample;           // last output, exposed for debug
} Oscillator;               // O(1) state

typedef struct {
  int    state;             // IDLE=0, ATTACK, DECAY, SUSTAIN, RELEASE
  double g;                 // current VCA gain in [0,1]
  double attack, decay, sustain, release;  // seconds / level
  double lambda_a, lambda_d, lambda_r;     // cached exp(-1/(fs*tau))
  double peak;              // velocity/127, set on note-on
} ADSR;                    // O(1) state

typedef struct {
  double b0,b1,b2,a1,a2;   // a0 normalized to 1
  double s1,s2;            // TDF2 delay registers
} Biquad;                  // 2 regs + 5 coeffs

typedef struct {
  int         active;      // 0 free / 1 playing
  int         note;        // MIDI note for note-off matching
  double      age_samples; // for stealing tiebreak
  double      gain;        // per-voice master scale
  Oscillator  osc[2];      // detune pair
  ADSR        env;
  Biquad      filter;
} Voice;                   // O(1) state

typedef struct {
  FilterType type;
  double     cutoff_hz, q, gain_db;
} VoiceFilterCfg;

typedef struct {
  double      master_gain;          // 0..1 (clamped [0,2])
  int         polyphony;            // V
  int         osc_count;            // fixed 2
  OscKind     osc_kind[2];
  double      osc_detune[2];
  double      osc_level[2];
  int         osc_wavetable[2];
  VoiceFilterCfg filter;
  double      adsr[4];              // a,d,s,r
} Patch;

typedef struct ResonataEngine {
  double  fs, fn;
  double  n_global;
  Patch   patch;
  int     voice_count;              // == patch.polyphony
  Voice*  voices;                   // pool of voice_count
  double  (*tables)[2048];         // M x L wavetable bank (M=10, L=2048)
  int     table_count;             // M
} ResonataEngine;                  // opaque handle
```

### 3. The exact C / WASM ABI (`core/resonata.h`)

```c
#define RESONATA_OK        0
#define RESONATA_ERR_PARSE 1
#define RESONATA_ERR_PARAM 2

typedef enum {
  RES_PARAM_MASTER_GAIN = 1,
  RES_PARAM_POLYPHONY,
  RES_PARAM_FILTER_CUTOFF, RES_PARAM_FILTER_Q, RES_PARAM_FILTER_GAINDB,
  RES_PARAM_FILTER_TYPE,
  RES_PARAM_ADSR_ATTACK, RES_PARAM_ADSR_DECAY,
  RES_PARAM_ADSR_SUSTAIN, RES_PARAM_ADSR_RELEASE,
  RES_PARAM_OSC1_KIND, RES_PARAM_OSC1_DETUNE, RES_PARAM_OSC1_LEVEL,
  RES_PARAM_OSC2_KIND, RES_PARAM_OSC2_DETUNE, RES_PARAM_OSC2_LEVEL,
  RES_PARAM_WAVETABLE_ID
} ResonataParam;

ResonataEngine* resonata_create(double sample_rate);
void            resonata_destroy(ResonataEngine* e);
int             resonata_note_on(ResonataEngine* e, int midi, int velocity);
int             resonata_note_off(ResonataEngine* e, int midi);
int             resonata_set_patch(ResonataEngine* e, const char* json, int json_len);
int             resonata_set_param(ResonataEngine* e, int id, double value);
int             resonata_render(ResonataEngine* e, float* out, int frames);
```

ABI semantics (binding for the Builder):

- `resonata_create(fs)` allocates the voice pool and wavetable bank once, builds
  all `M=10` tables at `f0=20 Hz` with `L=2048`, loads the default patch, returns
  an opaque handle. Accepts any `fs >= 8000`; recomputes coefficients from it.
- `resonata_note_on(e, midi, vel)` computes `f = 440*2^((midi-69)/12)`; allocates a
  free voice (reset phases, ATTACK with `peak = vel/127`, store `note`) or steals
  the quietest active voice by `env.g` (oldest as tiebreak).
- `resonata_note_off(e, midi)` finds the matching active voice, moves it to
  RELEASE from its current `g` (fast-release guard: never snaps to 1.0 first).
- `resonata_set_patch(e, json, len)` parses the versioned `resonata-patch` JSON;
  unknown keys ignored, missing keys fall back to defaults, out-of-range values
  clamped (`cutoffHz` to `(20, fn-20)`, `q` to `(1e-4, 100)`, gains `[0,2]`,
  ADSR times `[0,60]`). On parse failure it keeps the prior valid patch and
  returns `RESONATA_ERR_PARSE` (never crashes).
- `resonata_set_param(e, id, value)` live-tweaks the engine patch between render
  calls (per block, not per sample). `MASTER_GAIN`, `FILTER_*` and `ADSR_*`
  apply immediately to active voices on the next render; `OSC_*` kind/level/detune
  apply to subsequent note-ons (documented; optional ramping to live voices is a
  stretch). `FILTER_CUTOFF/Q/GAINDB` trigger a per-voice coefficient recompute.
- `resonata_render(e, out, frames)` advances every active voice `frames` samples
  in blocks of `N=128`, summing `tanh(master_gain * sum)` into the `float32`
  `out` buffer. No allocation. Returns `RESONATA_OK`.

### 4. Build pipeline (same sources -> native + wasm)

`resonata/Makefile`:

- `CC = cc`, `EMCC = emcc`, `CORE_SRCS = $(wildcard core/*.c)`.
- `make test` -> `$(CC) $(CORE_SRCS) test/test_*.c test/fft.c -Icore -lm -o build/resonata_test && ./build/resonata_test`.
  Runs the whole `assert` suite natively (reference `fs = 48000`); exits non-zero
  on any failure so CI fails fast.
- `make wasm` ->
  `$(EMCC) $(CORE_SRCS) wasm/exports.c -O3 -s STANDALONE_WASM=1 -s WASM=1
   -s ALLOW_MEMORY_GROWTH=1
   -s EXPORTED_FUNCTIONS='["_resonata_create","_resonata_destroy","_resonata_note_on","_resonata_note_off","_resonata_set_patch","_resonata_set_param","_resonata_render","_malloc","_free"]
   -s EXPORTED_RUNTIME_METHODS='[]'
   -o ui/resonata.wasm`
  `STANDALONE_WASM=1` yields a wasm that needs no emscripten JS runtime and can be
  `WebAssembly.instantiate`d directly inside the AudioWorklet. The only runtime
  imports are `memory` and the `malloc`/`free` it exports.

No third-party C dependency is pulled into either binary: the JSON parser and the
test FFT are both vendored and tiny (keeps the WASM footprint minimal and satisfies
the spec's "no large dependency in the WASM binary" rule).

### 5. UI / front end (`ui/`)

- `index.html` is fully client-side, served at `/resonata/index.html` by Pages.
- `resonata.js`: a ~40-line ES module that fetches `resonata.wasm`,
  `WebAssembly.instantiate`s it, and wraps the 7 functions. JSON is marshaled by
  `malloc`-ing wasm memory, copying the UTF-8 patch bytes, calling
  `resonata_set_patch`, then `free`-ing.
- `worklet.js`: an `AudioWorkletProcessor`. On construction it instantiates the
  wasm and calls `resonata_create(ctx.sampleRate)`, caching the engine handle. In
  `process()`, it calls `resonata_render` to fill the output channel for the block
  (real sample-accurate timing, no `setTimeout`). It receives `noteon`/`noteoff`/
  `param`/`patch` messages on `port` and calls the corresponding wasm export. It
  periodically posts a small scope snapshot (a downsampled ring of the last ~2048
  samples) back to the main thread via `port.postMessage` for visualization.
- `main.js`: builds the control surface from `default-patch.json`:
  - Oscillator A/B kind selector, detune (cents) and level sliders.
  - Filter type dropdown + cutoff / Q / gain-dB knobs (log cutoff mapping).
  - ADSR: four sliders with a live drawn envelope curve.
  - Master gain and polyphony count.
  - A virtual piano: clickable keys + QWERTY mapping (`a w s e d f t g y h u j k`
    -> C4..C5) sending `noteon`/`noteoff` to the worklet.
  - "Load patch" / "Save patch" JSON file buttons (Download Blob / `<input type=file>`).
  - An oscilloscope `<canvas>` drawing the worklet's scope snapshots, plus an RMS
    meter.
- `styles.css`: dark, monospace-lab aesthetic consistent with the rest of the
  Random site.

Determinism: the core never calls `clock()`/`rand()` on the hot path, so the native
tests and the browser instrument are bit-for-bit reproducible for a given input.

### 6. Hosting / Pages layout

Per the lab's Pages rules, the entrypoint is `/resonata/index.html`. Pages builds
from `main`; the `ui/` folder is committed to the repo, and Pages is configured to
serve it at `/resonata/`. The `resonata.wasm` must be served with
`Content-Type: application/wasm` (GitHub Pages already does this), and the worklet
is loaded via `audioWorklet.addModule('worklet.js')` which must be same-origin.
`default-patch.json` is fetched at runtime and is also human-readable on Pages.

## Test Matrix (native `make test`, fs = 48000)

Each maps to a `test_*.c` file and to a spec section:

1. **Oscillator** (`test_osc.c`, spec 3): 2048-pt FFT of 1 s sine/saw; peak within
   +/-1 bin of `round(f/(fs/NFFT))`; PolyBLEP saw energy above `fn` below signal by
   >= 40 dB for `f <= fn/4`.
2. **Wavetable** (`test_wavetable.c`, spec 4): mid-band output matches analytic
   band-limited harmonic sum within 1e-3 RMS; cross-table switch discontinuity
   <= 1e-2.
3. **ADSR** (`test_adsr.c`, spec 5): attack reaches >= 0.99 within `attack_time
   +/- 5%`; decay converges to `sustain` within 1e-3; release falls below 1e-3
   within `release_time +/- 5%`; fast-release guard verified.
4. **Biquad** (`test_biquad.c`, spec 6): for each type, magnitude at `f0` within
   0.5 dB of target (LP at `fn/4`: -3 dB; 0.5*f0: 0 dB; 2*f0: <= -12 dB); 1e6-sample
   impulse response finite (`|y| < 1e3`); debug assert `|a2| < 1`.
5. **Polyphony** (`test_poly.c`, spec 7): note-on allocates a voice; note-off frees
   it after release; with the pool exhausted, stealing selects the quietest
   `env.g` active voice (oldest tiebreak).
6. **Patch** (`test_patch.c`, spec 8): serialize default patch -> parse -> assert
   field-for-field equality of re-serialized form; clamping enforced; malformed
   JSON returns `RESONATA_ERR_PARSE` and leaves the prior patch intact (no crash).
7. **End-to-end** (`test_e2e.c`, spec 10): render a 0.5 s note and assert the RMS
   envelope rises, sustains, then falls, matching the ADSR shape within tolerance.

UI verification (dynamic, by the Tester): load `/resonata/`, confirm a tone plays
on key press, the scope animates, filter/ADSR sliders change the timbre audibly,
and a saved patch reloads byte-for-byte.

## Complexity budget (from spec 11)

Per block of `N=128` at `fs=48000`, `V=16`: `O(N*V)` trivial arithmetic, no
allocation on the hot path. Roughly 6.1M voice-samples/sec, comfortable even under
WASM baseline JIT. Internal oscillator/filter state is `double`; only the final
`out` buffer is `float32`.
